# 🔑 Command-Line Password Generator

A lightweight, secure, and user-friendly command-line tool built in Python that generates random passwords based on your custom criteria.

---

## 🚀 Features

* **Customizable Length:** Choose exactly how long you want your password to be.
* **Character Set Preferences:** Mix and match uppercase letters, lowercase letters, numbers, and symbols.
* **Input Validation:** Safely handles typos or invalid choices without crashing.
* **Fallback Protection:** Automatically defaults to a safe setup if no character types are selected.

---

## 🛠️ Requirements

* **Python 3.x** Installed on your system.
* Built entirely using Python's standard libraries (`secrets` and `string`), so **no external installations or pip packages are required**.

---

## 💻 How to Run It

1. Make sure you have **Python 3** installed on your computer.
2. Open your terminal or command prompt and navigate to the folder containing your script.
3. Run the script using Python:
   ```bash
   python generator.py
