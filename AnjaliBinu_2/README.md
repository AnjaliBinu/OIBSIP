# 🧮 Command-Line BMI Calculator

A clean, beginner-friendly Python command-line tool that calculates a user's Body Mass Index (BMI) and classifies it into standard health categories.

## ✨ Features
- **User Input Validation:** Gracefully handles typing errors (like text inputs instead of numbers).
- **Mathematical Safety:** Automatically blocks values less than or equal to zero to prevent impossible calculations.
- **Smart Unit Detection:** Cleverly detects if you entered your height in centimeters (e.g., 175) instead of meters (e.g., 1.75) and auto-converts it for you!
- **Instant Categorization:** Classifies your score immediately into standard healthcare ranges (Underweight, Normal, Overweight, or Obese).

## 🚀 How to Run It

1. Make sure you have **Python 3** installed on your computer.
2. Open your terminal or command prompt and navigate to the folder containing your script.
3. Run the script using Python:
   ```bash
   python bmi_calculator.py
